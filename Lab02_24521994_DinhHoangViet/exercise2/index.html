Milestone 3: Root Event Delegation Test Bench

Kiểm tra cơ chế phân phối sự kiện tập trung tại root element theo kiến trúc Reactive Mini-Engine.

🔍 Hướng dẫn kiểm tra bằng DevTools

  1. Kiểm tra listener tại Root:
    Mở tab Elements, chọn <div id="root">, mở tab Event Listeners ở góc phải → Có đúng 1 listener click.
  2. Kiểm tra Button & Span con:
    Chọn <button id="test-btn"> hoặc <span id="inner-span">, bỏ tick Ancestors trong tab Event Listeners → Không có bất kỳ listener nào được gắn trực tiếp.
  3. Kiểm tra bằng Console:
    getEventListeners(document.getElementById('root')) → { click: [...] }
    getEventListeners(document.querySelector('#test-btn')) → {} (Rỗng)
    getEventListeners(document.querySelector('#inner-span')) → {} (Rỗng)
  4. Một click = Một lần cập nhật:
    Click vào icon hoặc chữ <span> bên trong button → Click Counter tăng đúng 1 đơn vị, bất kể ứng dụng đã qua bao nhiêu lần re-render.
